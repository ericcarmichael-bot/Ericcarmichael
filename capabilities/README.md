# Capabilities

One folder per capability I can demonstrate — `marginal-analysis`, and more as engagements add to the list. Never a folder named for a course or a term.

Each capability folder holds a `README.md` (what the capability is, and which engagements exercised it) and a `spec.md` (the method: model design, formula logic). The engagements that prove the capability live in `docs/`, `data/`, and `analysis/`.
